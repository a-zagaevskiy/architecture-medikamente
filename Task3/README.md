# Оценка Data Encryption at Rest and In Transit

| **Данные** | **В чем необходимость защиты** | **Инструменты защиты** |
| :-: | :- | :- |
| Персональные данные пациентов | Соответствие требованиям 152-ФЗ о защите персональных данных | * Хранение в шифрованном виде с использованием современных криптографических алгоритмов (например, AES-256) </br> * Передача по защищенным каналам связи (TLS 1.3) </br> * Доступ на основе ролей (RBAC) |
| Медицинская документация, анализы | Соответствие требованиям 152-ФЗ о защите персональных данных | * Хранение в шифрованном виде с использованием современных криптографических алгоритмов (например, AES-256) </br> * Доступ на основе ролей (RBAC) </br> * Передача по защищенным каналам связи (TLS 1.3) </br> * Передача за пределы системы сопровождается обфускацией (может использоваться токенизация, когда персональные данные пациента заменяются идентификаторами) |
| Финансовые данные | Коммерческая тайна | * Хранение на шифрованных дисках </br> * Передача по шифрованным каналам связи (TLS 1.3) </br> * Использование обфускации (токенизация персональных данных) |
| Внутренние данные системы | В целях противодействия взлому или компроментации | * Передача по шифрованным каналам связи (TLS 1.3) </br> * Доступ на основе ролей (RBAC) |
